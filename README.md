# 六人好友德州扑克

公开 Sites 网页，昵称即可开桌，最多六位真人，空位由规则机器人补齐。

## 在线试玩

[打开六人好友德州扑克](https://friends-poker-table-zh.wffyffqff.chatgpt.site)

直接使用浏览器打开上述首页，无须下载源码、安装软件或登录 GitHub / ChatGPT。

1. 输入昵称，按需设置起始筹码、行动限时和总手数，点击“创建新房间”。
2. 进入牌桌后，点击“复制邀请”，将生成的完整邀请链接发给朋友。
3. 朋友打开邀请链接，输入昵称加入房间；房主开始牌局即可一起玩。最多六位真人，空位由规则机器人补齐。
4. 想自己开另一桌时，重新打开上面的游戏首页，再创建新房间即可。

请分享页面生成的完整邀请链接，其中包含入座凭证；只发房间号无法代替邀请链接。同一浏览器的标签页共享玩家身份，多人同设备试玩时请使用不同浏览器或独立配置。

线上网站与 GitHub 仓库的可见性相互独立：即使仓库为私有，朋友仍可通过上述链接试玩。网站能否打开取决于所在网络对现有域名的访问情况。

下载源码自行运行请看下方“本地运行与验证”；本机 localhost 地址不能直接供异地朋友访问。

## 身份与房间规则

- 服务器生成 256 位随机访客凭证，HttpOnly Cookie 保存 30 天，数据库只存凭证哈希。
- 同一浏览器刷新或重开原房间链接恢复座位；清除 Cookie、过期或换设备后会成为新玩家。
- 房主在手牌结束后可手动转让权限给已入座的真人，旧房主保留座位；转让与移出玩家都会轮换邀请链接。
- 点击设置中的“离开牌桌”会等待服务器确认，然后由电脑立即接管原座位；手牌、筹码、已下注额及行动进度保持不变。
- 网页轮询同时发送在线心跳。关闭网页或断网后，自最后一次成功心跳起保留 30 秒原座位，期限内刷新可恢复；超时后由电脑接管，需用有效邀请链接重新入座。
- 不限时房间可在创建时开启“不掉线模式”，房主重开时也能调整。开启后关闭网页或断网仍保留座位、筹码、手牌和房主权限，轮到离线真人时等待其回来；主动退出、房主手动转让及移出玩家照常有效。限时房间不提供此模式，旧房间默认关闭。
- 从不掉线切回普通模式需要房主重开；重开后所有座位重新获得完整的 30 秒重连宽限期。保留座位仍依赖有效的浏览器身份，清除 Cookie、身份过期或换设备不会自动认回原玩家。
- 房主主动退出或断线超时后，按座位顺序自动交给仍在宽限期内的真人，并轮换邀请链接。无人留下时不指定房主；下一位持有效邀请链接加入的人成为房主。
- 开局、重置、移出玩家仅房主可执行。所有页面关闭时不运行后台牌局；再次访问房间时服务器先清理超时座位。不要把同一浏览器的多个标签页当作不同玩家；任一标签主动退出都会释放该身份的座位。
- 身份与昵称分开；请求中的 guestId 不被用作认证。接口校验同源、房间版本和玩家座位。
- 新建房间限制每个当前房主身份每小时十次。公开匿名访问仍需按实际流量观察防滥用需求。
- 原已登录房主首次建立 Cookie 时保留账号对应身份。历史未登录访客的客户端 ID 不再被信任，需用当前邀请链接重新入座。

## 技术栈与目录

TypeScript、React、Vinext / Vite、Cloudflare Workers / D1、Drizzle。

GitHub Actions 在提交和拉取请求时执行依赖安装、57 项自动测试、生产构建及类型检查。

- `app/`：牌桌界面、动画组件与房间 API。
- `lib/`：牌局规则、下注计算、房间状态和访客会话。
- `db/`、`drizzle/`：数据库结构及迁移文件。
- `tests/`：牌型、筹码、行动顺序、权限、会话及动画测试。
- `worker/`：服务端入口；`public/`：页面静态资源。

## 本地运行与验证

需要 Node.js >=22.13 和 npm。

```sh
npm ci
npm run dev
```

打开终端显示的本地网址（通常是 http://localhost:3000）。本地使用 Wrangler / Miniflare 模拟 D1，房间与会话表会自动初始化；数据保存在忽略的 `.wrangler/` 中，无须填写模型 API 密钥。

```sh
npm test
npm run build
```

本地服务器保持运行时，可在另一终端执行 `node tests/session-http.mjs`，验证六人加入、Cookie 身份及房主权限交接。`node tests/room-presence-http.mjs` 验证普通模式断线接管，`node tests/room-mode-http.mjs` 验证不掉线模式保留及重连；后两项分别包含真实 32 秒等待。这些脚本只允许连接本机服务，会在本地创建测试房间；可用进程环境 `POKER_TEST_URL` 指定本机端口。

需要运行 `tsc --noEmit` 时，先执行构建，再执行 `npx wrangler types --config dist/server/wrangler.json` 生成忽略的 Cloudflare 类型文件。

## 部署说明

项目包含服务端与 D1 数据库，不能仅通过 GitHub Pages 的静态托管运行。`.openai/hosting.json` 只保留本地所需的 `DB` 绑定声明，不包含原线上项目 ID。自行部署需要创建自己的托管项目和数据库，再配置项目标识与绑定。

原线上演示：[打开六人牌桌](https://friends-poker-table-zh.wffyffqff.chatgpt.site)。

## 运行限制

网站继续使用原 GPT/Sites 域名。免登录解决了创建房间的账号步骤，域名的地区网络可达性仍取决于访问环境。
同浏览器不同标签共享一个访客身份；多人同设备测试请使用不同浏览器配置。
仅虚拟筹码娱乐，不提供充值、提现或资金结算。

## 下注操作与动画时序

- 下注区统一保留 2.0 / 2.5 / 3.0 / 4.0 BB 四个快捷选项及一条滑动条；快捷金额为本轮下注或加注至的总额，不合法的选项置灰。
- 滑条旁显示所选 BB 与筹码数，较大数值使用 K / M 等缩写；悬停可查看完整筹码数。
- 滑条从最低合法下注到全下，通常每格 0.5 BB，末格可精确到全下零头。选择金额后点击下注或加注按钮提交。
- 本机动画队列、未处理事件和服务器行动门限全部完成后，才显示下一位思考/行动提示并开放操作；人机随后等待再行动。
- 默认完整开启动画；可在“设置”中主动开启“减少动画”，并在本机记住选择。减少动画仍保留短暂发牌/弃牌反馈。重新加入牌局直接恢复当前状态，不重播已经发生的动作。

## 界面与交互

- 简约半透明布局，提供亮色和炭灰暗色切换，并记住本机主题；牌面保持白色实底。
- 下注快选、滑条、BB / 筹码读数和行动按钮集中在同一面板；设置菜单集中提供动画偏好、重开和离开。
- 筹码使用平滑计数动效，BB 固定一位小数，按 0.1 BB 递进到目标；实际提交始终使用所选合法金额。
- 本轮动态默认收起，展开后可拖动；窄屏保留完整下注和行动区域。弹窗支持键盘焦点、Escape 关闭及焦点恢复。
